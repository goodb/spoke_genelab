4. BIOLINK ENTITY PROPERTIES
================================================================================

Standard Biolink Properties:
  biolink:id          - Entity identifier
  biolink:name        - Entity name
  biolink:description - Entity description
  biolink:symbol      - Gene symbol
  biolink:category    - Entity category (for GO terms)
  biolink:in_taxon    - Organism/taxonomy information

Reification Properties (for Associations):
  biolink:subject     - Subject of the association
  biolink:predicate   - Predicate URI of the association
  biolink:object      - Object of the association

5. SPOKEGENELAB CUSTOM EXTENSIONS
================================================================================

Quantitative Properties (on reified associations):
  spokegenelab:log2fc        - Log2 fold change (float)
  spokegenelab:adj_p_value   - Adjusted p-value (float)
  spokegenelab:p_value       - Raw p-value (float)
  spokegenelab:effect_size   - Effect size (float)

Study Properties:
  spokegenelab:project_title          - Full project title
  spokegenelab:project_type           - Project type (e.g., "Gene Expression Atlas")
  spokegenelab:source                 - Data source (e.g., "GEA")
  spokegenelab:study_id               - Study identifier
  spokegenelab:experiment_accession   - Experiment accession
  spokegenelab:submitter_name         - Submitter name
  spokegenelab:submitter_email        - Submitter email
  spokegenelab:submitter_affiliation  - Submitter affiliation
  spokegenelab:pubmed_id              - PubMed ID
  spokegenelab:secondary_accessions   - Secondary accessions

Assay Properties:
  spokegenelab:contrast_id            - Contrast identifier
  spokegenelab:technology             - Technology type
  spokegenelab:measurement            - Measurement type
  spokegenelab:reference_group_id     - Reference group ID
  spokegenelab:reference_group_label  - Reference group label
  spokegenelab:test_group_id          - Test group ID
  spokegenelab:test_group_label       - Test group label
  spokegenelab:experimental_factors   - Experimental factors
  spokegenelab:array_design           - Array design information

Gene Properties:
  spokegenelab:ncbi_gene_id   - NCBI Gene ID
  spokegenelab:ensembl_id     - Ensembl ID
  spokegenelab:id_source      - ID source ("NCBIGene" or "Ensembl")

Enrichment Properties:
  spokegenelab:enrichment_type    - Type of enrichment (GO, Reactome, InterPro)
  spokegenelab:term_id            - Term identifier
  spokegenelab:genes_significant  - Count of significant genes
  spokegenelab:genes_total        - Total genes in term
  spokegenelab:source             - Source database

6. REIFIED ASSOCIATIONS
================================================================================

Differential expression relationships are reified to preserve quantitative data.

Association Class: biolink:GeneExpressionMixin

Structure:
  <spokegenelab:Association/{hash}>
      a biolink:GeneExpressionMixin ;
      biolink:subject <assay_uri> ;
      biolink:predicate biolink:affects_expression_of ;
      biolink:object <gene_uri> ;
      spokegenelab:log2fc "value"^^xsd:float ;
      spokegenelab:adj_p_value "value"^^xsd:float .

Differential methylation uses biolink:Association class.
